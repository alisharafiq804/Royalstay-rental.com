# RoyalStay Rentals — Complete Frontend Project

A polished HTML/CSS/JavaScript rental website for RoyalStay Rentals.

## Included
- Sign-up and sign-in gate using browser localStorage (frontend demo; no server/database).
- Home, property collection, girls hostel, flats, royal houses, gallery and contact sections.
- 1-seater and 2-seater hostel options with day/week/month pricing.
- Booking modal with name, CNIC/ID, property, date, duration and message.
- Responsive mobile navigation.
- Animated reveal effects and custom cursor on desktop.
- Light/dark theme toggle.
- Gallery category filtering.
- Flat image thumbnail switcher.
- User-supplied reference images included under `assets/`.

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Important
This is a frontend-only project. Signup/login and booking data are demo-only and stored locally in the browser. For production, connect the forms to a backend/database and add real authentication, availability, payment and admin management.
